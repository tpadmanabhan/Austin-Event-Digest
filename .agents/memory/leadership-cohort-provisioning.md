name: Leadership cohort provisioning
description: Future Leadership cohorts use separate organization tenants and subdomains; the intake page is not set up.
---

Future Leadership cohorts are intended to be separate organization tenants, each with its own subdomain under `irl.group`, following the subdomain setup pattern used for City IRLs. The existing Leadership Austin “Add class” control only adds a class-profile card to the current `leadershipaustin` tenant; it does not create a new cohort site.

The self-service intake page for new cohorts has not been set up. Do not direct people to it or claim cohort signup is self-service. Before provisioning a new cohort, confirm its details and the approved intake/provisioning path.

**Why:** the user clarified that future cohorts will get separate subdomains like the City IRLs and that the new-cohort intake page is not yet available.

**How to apply:** distinguish profile edits on the existing Leadership Austin site from new cohort tenant rollouts. For the latter, follow the alumni tenant rollout and tenant-routing skills; do not assume Leadership Austin's existing events, admins, links, or email configuration carry over.
