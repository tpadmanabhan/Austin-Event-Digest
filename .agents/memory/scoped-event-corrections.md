name: Scoped event corrections
description: Why the user chose single-link editing rather than rewriting entire editions.
---

For an event URL correction, the user chose to add single-link editing rather than re-save complete original event lists, even though the narrow edit required publishing new code first.

**Why:** The user explicitly selected the link-only editing option when the live API could not change a link.

**How to apply:** Prefer scoped changes for individual event corrections. Do not treat an unavailable live editing capability as permission to replace the full edition array.
